## Активная работа

**Этап 2 — Оплата Продамус (разовая).** Код готов и локально проверен, ждём боевой ключ Продамуса + деплой для живого закрытия.

Сделано: миграция `0006` (таблицы `payments`, `subscriptions`); `services/prodamus.py` (Hmac-подпись, сборка payform-ссылки, разбор `products[...]` из вебхука); `services/payments.py` (старт оплаты по тарифу + обработка вебхука); `repo.py` (создание платежа, идемпотентный `activate_payment`, реальный `get_active_subscription`); приёмник вебхука `src/webapp.py` (aiohttp в процессе бота, `:8080/prodamus/webhook`, поднят рядом с polling); хендлер `pay:create` отдаёт рабочую кнопку-ссылку; тексты оплаты.

Локальная верификация (Docker): 6 автотестов подписи/разбора зелёные; end-to-end smoke по HTTP — битая подпись → 400 (подписки нет), валидный вебхук → 200 + создана подписка (990 ₽, 07.07→07.08), повтор вебхука → без дубля (идемпотентность), платёж `succeeded`. Миграция `0006` применена в схеме `maria_doll`.

**Осталось для закрытия (живая проверка человеком):** заказчица даёт секретный ключ payform + прописывает «URL для уведомлений» в ЛК Продамуса; деплой (этап 7) даёт публичный HTTPS `https://dolbikfit.ru/prodamus/webhook`; затем реальная оплата → вебхук → подписка. Только после этого — чекбоксы ROADMAP `[x]` и тег `stage-2-done`. Домен `dolbikfit.ru` → `87.58.210.8` уже в DNS.

## Протокол обновления

**При старте сессии**:
1. Прочитать этот файл.
2. `git tag -l "stage-*"` и сверить с колонкой «Закрывающий тег». Тег без записи в таблице = таблица устарела, обновить.
3. `git log --oneline -10` — что менялось последним.
4. Только после этого приступать к работе.

**При взятии этапа в работу**:
1. Обновить «Текущий этап» и «Активная работа».
2. Статус 🚧 в таблице.
3. Закоммитить отдельно: `chore(status): start stage N`.

**При закрытии этапа**:
1. Убедиться, что все чекбоксы в `07_ROADMAP.md` отмечены `[x]` и реально проверены.
2. Создать тег: `git tag stage-N-done -m "<описание>"`.
3. В таблице: ✅, «Закрывающий тег», «Последний коммит», «Дата закрытия».
4. Добавить запись в «Историю закрытий».
5. Указать новый «Текущий этап» и «Следующий шаг».
6. Закоммитить: `chore(status): close stage N`.

**Если этап заблокирован**:
1. Статус ⏸ в таблице.
2. В «Известные блокеры»: что блокирует, кого ждём, что нужно для разблокировки.

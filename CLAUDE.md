# CLAUDE.md — Telegram-бот платного клуба @Fit_it_bot (maria_doll)

Бот платного клуба с подпиской: приём заявок, оплата через **Продамус**,
авто-управление доступом в закрытую группу, напоминания о продлении, промокоды,
рассылки по сегментам + **веб-админка** (рабочий кабинет заказчицы).

Клиент — Maria_Doll (проект dolbikfit, фитнес). Бот `@Fit_it_bot`.

## Старт сессии (обязательно)

Перед любой работой — ритуал okplan:
1. Прочитать `docs/STATUS.md` — текущий этап, активная работа, блокеры.
2. `git tag -l "stage-*"` — сверить с колонкой «Закрывающий тег» в STATUS. Тег без записи = STATUS устарел, сначала починить.
3. `git log --oneline -10` — что менялось последним.
4. Открыть `docs/07_ROADMAP.md` на текущем этапе — чекбоксы открытых acceptance-пунктов.

Прогресс — по методологии **okplan** (три слоя правды: STATUS.md → чекбоксы ROADMAP → git-теги `stage-N-done`). Тег ставится только после живой верификации человеком. Не отмечать чекбоксы и не ставить теги наперёд. За 1 заход — 1 этап, потом человек проверяет.

- **Оплата — Продамус, разовый платёж** через payform (`dolbikfit.payform.ru`), подтверждение **вебхуком** на HTTPS-эндпоинт (домен есть). Реккуренты — этап 8, когда Продамус одобрит.

- **Промокоды** — заказчица создаёт сама из админки (код, цена/скидка, срок, лимит применений).
- **Рассылки по сегментам**: активные / кому скоро заканчивается / ушедшие.
- **Веб-админка** — на домене `dolbikfit.ru`, рабочий кабинет: дашборд (выручка/оплаты/окончания/ушедшие), подписки, тарифы, промокоды, рассылки, настройки и тексты.
- **На будущее**: заложить связку под второй бот (дневник питания/КБЖУ по фото) в тот же кабинет — отдельная оплата. Пока не реализуем, только не мешать.
